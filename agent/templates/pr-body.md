# Pull request body

Title: `type(scope): subject`

Use these headings in this order. Remove a heading that is empty. 40 lines maximum.

```
## Why
<the goal, in one or two sentences>

## What changed
- <one line for each change>

## Scope
<what this pull request does not do>

## Tradeoffs
<only the alternatives that a reviewer would ask about, and why you rejected them>

## Blast Radius
<what else this change can affect, and the one fact that makes it safe>

## Verification
<the checks that ran, the evidence, links to logs, videos, or screenshots>
```
