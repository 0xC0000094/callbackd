# Resume note

Write this in `logs/<task>-resume.md` when work pauses.

```
Intent:          <the goal>
What I was doing: <the current step>
Progress:        <what is done, and what is verified>
Current state:   <branch, commits, whether the tree builds>
Next steps:      <the first action on resume, then the rest>
Key files:       <paths>
Gotchas:         <traps that cost time>
```
