# Playbook: Pause safely

**You own a clean stop. Use it only when the human asks.**

## Steps

1. Stop at a safe boundary. Stop any delegates.
2. Do no irreversible action. Open no new pull request.
3. Make one `wip:` commit. If the tree is broken, say so in one line.
4. Write a resume note with `agent/templates/resume-note.md` in `logs/`.
5. Reply: what is on disk, what is not, and the first action on resume.
