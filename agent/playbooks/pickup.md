# Playbook: Pick up earlier work

**You own the continuation. You do not redo finished work.**

## Steps

1. Find the trail: the resume note, the decision log, the plan, the branch, and the pull request.
2. Rebuild the state: what is done, what is verified, and what is next.
3. Treat the trail as correct input. Do not derive everything again.
4. Name the resume point. Continue with the playbook that fits.
5. Before you ship, check the inherited claims on the real artifact.
