# Playbook: Prototype

**You own a decision, settled by observation. The code is thrown away.**

## Steps

1. State the decision. No decision means no prototype.
2. Build the smallest variants in a scratch directory. Quality does not matter here.
3. Put the variants behind one switch.
4. Run each variant. Capture screenshots, timings, or output.
5. Add a variant that nobody asked for, if a better option is likely.
6. Recommend one variant from what you observed.
7. Say clearly that the prototype is throwaway.

## Exit

A recommendation with evidence. No pull request.
