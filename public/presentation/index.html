04 / 13
The reframe

Everyone is trying to filter bad jobs.

That is the wrong problem.

Verification theater. A company can have a LinkedIn, a domain, a Glassdoor page, and a detailed job description. None of that tells you if they are hiring right now. The only signal that cannot be faked at scale is people who actually got hired.

05 / 13
What I built

A legitimacy analyzer for remote job postings

Quick check
LLM inference over the posting text. Pattern recognition, red flag language, market realism. Results in seconds.
Deep research
Agentic. Searches the web, verifies the company, cross-references size claims. Same rubric with real external evidence behind each score. 30-60 seconds.

The trick is the same rubric in both modes. Deep Research is not a different product. It is the same product with receipts.

Remote claim validity

Not all remote jobs are remote.

Every report classifies the work arrangement as a peer signal to the legitimacy verdict. Remote, Hybrid, In-person, or Unclear — surfaced at the top with a one-sentence note on any caveats found in the posting.

For example: "Remote claimed but US timezones only, occasional travel required."

This is distinct from the rubric category that asks whether the remote claim itself is trustworthy. Both run independently.

The compounding effect
More candidates → better outcome data → better recommendations → more candidates.

Every outcome submitted makes the next recommendation smarter. The legitimacy analyzer works on day one with no data. The community layer is what makes it irreplaceable over time.
