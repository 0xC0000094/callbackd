# Kit feedback

Write here when a kit file (`AGENTS.md` or `agent/`) is wrong, unclear, or missing something. Do not change the kit file. The kit maintainer reads this file and updates the kit.

Status is `open`, `handled in kit X.Y.Z`, `rejected: <reason>`, or `waiting: <reason>`. Change the status when the kit maintainer reports a decision.

| Date | Kit file | Problem (one sentence) | Evidence (link or path) | Suggested change | Status |
|---|---|---|---|---|---|
| <YYYY-MM-DD> | <path> | <what went wrong> | <log, PR, or transcript> | <one sentence> | open |
